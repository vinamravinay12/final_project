# Final project

This repository contains the Final project for the Emotion Detection application.

The application uses Watson NLP to analyze text and identify emotion scores for:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also determines the dominant emotion in the provided text.

The project includes:

- Emotion detection using Watson NLP
- Python packaging with the EmotionDetection package
- Unit testing
- Flask web deployment
- Error handling for invalid input
- Static code analysis using PyLint
